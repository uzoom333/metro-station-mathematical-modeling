# Project Scope

Version 2 computationally redevelops the single-station ventilation and thermal
problem from the 2024 project. It retains the original logical decomposition,
major variables, assumptions, and Differential Equations/Calculus II
methodology, then adds new coupled equations, software, scenarios, and
experiments.

The objective is reproducible education and model exploration—not design,
certification, code compliance, or prediction for a real station.
