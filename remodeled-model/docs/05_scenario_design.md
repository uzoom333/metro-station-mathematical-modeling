# Scenario Design

Each scenario YAML extends `baseline.yaml`; the loader produces a complete
validated configuration, and each saved run includes that resolved YAML.

The cases isolate minimum occupancy, peak crowding, fixed ventilation, reduced
capacity, a hot day, extended train dwell, and a time-dependent ventilation
failure. Exact changes are stated in each file's metadata and in the V2 README.
They are synthetic experiments, not forecasts or emergency assessments.
