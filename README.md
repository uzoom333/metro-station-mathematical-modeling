# Metro Station Mathematical Modeling

This repository documents an award-winning undergraduate mathematical modeling
project developed in 2024 for the Mathematical Modeling Challenge at the
**X Congress of Science, Technology and Innovation at PUC Goiás**. The project
received **fourth place**.

The project studied the ventilation and thermal conditions of a single
hypothetical metro station. Using concepts from Differential Equations and
Calculus II, it decomposed the problem into interacting quantities: minimum
passenger occupancy, heat generated by passengers, heat generated by an
arriving train, airflow and air renewal, station volume, and temperature.
Multiple coupled differential equations connected these parts of the model.

The competition emphasized logical reasoning, mathematical modeling,
assumption definition, and problem decomposition. The project was therefore an
academic model of the station system, not a complete engineering design.

## Project versions

### Version 1: Faithful reconstruction

[`original-model/`](original-model/) preserves the original problem statement,
modeling methodology, logical reasoning, variables, engineering assumptions,
and mathematical approach. It presents how the project translated a complex
physical setting into a manageable mathematical model.

### Version 2: Future remodeling

[`remodeled-model/`](remodeled-model/) is reserved for a future expansion using
modern numerical simulation and software engineering practices. It will build
on Version 1 without rewriting the historical account of the 2024 project.

## Transparency

This repository faithfully reconstructs the original mathematical reasoning
while replacing numerical values and implementation details with illustrative
examples. Exact historical values, station dimensions, code, and diagrams are
not available; the repository does not invent experimental results,
measurements, or conclusions.

The Python example uses only the standard library:

```bash

```

Its parameters and output illustrate the preserved modeling approach; they are
not historical competition values or results.
